KHANHDUY Training Tracker V4 - GitHub Pages package

UPLOAD ALL FILES IN THIS FOLDER TO THE ROOT OF YOUR GITHUB REPOSITORY:
- index.html
- manifest.webmanifest
- sw.js
- icon-192.png
- icon-512.png
- .nojekyll

Then enable GitHub Pages from the main branch / (root).

Data is saved in the browser (localStorage). Use Backup JSON regularly.
If migrating from V3 on desktop, export Backup JSON in V3 and import it in V4 after opening the GitHub Pages site.
